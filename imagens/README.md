
# Imagens do Projeto

## Gráfico de Fechamento 
Mostra a variação do preço de fechamento das ações ao longo do tempo.

## Médias Móveis
Utilizado para identificar tendências de curto e longo prazo das ações.

## Boxplot Mensal
Apresenta a distribuição dos preços de fechamento por mês.

## Gráfico Candlestick
Mostra abertura, fechamento, máxima e mínima das ações em cada período.
